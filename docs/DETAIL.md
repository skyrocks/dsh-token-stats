# Token 用量

在「设置 → Token 用量」里看所有会话的 token 消耗：今日 / 本周 / 本月三张卡，日 / 周 / 月的趋势柱状图，
模型分布和会话排行。子代理会话一起算。

## 数据从哪来

会话日志里每条 `assistant/message`（以及失败 / 重试但报了用量的 `assistant/attempt`）都带 usage。
插件把整个日志折成一本账：先回填历史会话（带进度），之后只做增量。

- 日按本机时区切，周从周一开始，月是自然月。
- fork 继承来的前缀不重复计数。
- 只读：不调用模型、不改会话、不往会话里追加事件。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `historyDays` | 365 | 回填只看最近多久创建的会话 |
| `retainDays` | 400 | 账本保留天数（会被 `monthCount` 自动抬高） |
| `dayCount` / `weekCount` / `monthCount` | 14 / 12 / 12 | 趋势柱数 |
| `path` | `$DSH_HOME/token-stats/usage.json` | 账本位置 |

## 限制

- 只统计本地会话日志里带 usage 的结算；官网账单可能另含标题生成等内部调用，两者不必相等。
- 首次打开要读一遍历史日志，耗时取决于历史量；之后启动不再重扫。
- 账本只存计数（会话 id、事件序号、时间、模型、provider、四类 token），没有对话正文。
